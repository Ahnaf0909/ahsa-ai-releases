# AHSA AI: downloads

AHSA AI is a personal AI agent for Windows that runs on your own computer. It can work with your files, open apps, run commands, keep tasks and reminders, and remember what you ask it to, and it asks before doing anything sensitive.

This repository holds the installers only. The app checks here for new versions.

## Download

Get the latest version from the [Releases page](https://github.com/Ahnaf0909/ahsa-ai-releases/releases/latest):

- **AHSA-AI-Setup.exe**: the installer. Updates itself from inside the app (Settings → Updates).
- **AHSA-AI-Portable.exe**: runs without installing. Download a new copy to update.

Requires Windows 10 or 11, 64-bit.

## Before you install

The installer is not code-signed yet, so Windows will show a "Windows protected your PC" warning. Choose **More info → Run anyway** to continue. On PCs where Smart App Control is on, Windows may block the app completely until it is signed.

## Your data

Everything AHSA saves stays on your computer, in a folder you can choose. Nothing is sent anywhere unless you connect a cloud AI service yourself, and the app shows and records every such request.
